# Street Fighter Code

- É uma lingaugem escalável onde os comandos se equiparam a uma sequência de botões e comandos de um jogo de luta.
- A linguagem compõe várias features como o Timing (combo sincronizado), Assistentes (outros personagens), Troca de Personagens, que podem interpretar comandos básicos.

Tipos: Inteiros, Booleano

Comandos permitidos:
- Cima
- Baixo
- Esquerda
- Direita
- Jab
- Chute
- Agarrar
- Cima + Chute = Voadora
