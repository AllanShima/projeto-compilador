Palavras-chave = Palavras reservadas com significados variados Ex: combo, macro, baixo, frente, mov

Identificadores = Nomes atríbuidos a variáveis e funções 

Constantes = Valores fixos Ex: Integer (1), String ("RYu")

Operadores = Realizar operações Ex: ->

Símbolos especiais = Estruturação do código Ex: [] (matriz)
